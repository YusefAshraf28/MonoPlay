# MonoPlay Creative Arm

A client-facing 360 creative-arm skill library for MonoPlay.

Each skill must use the MonoPlay brand foundation and must not draw on The Playhaus strategy, campaigns, language, audience, or visual direction.

## Structure

- `brand-context.md`: MonoPlay source of truth
- `skills/<role>/SKILL.md`: role-specific workflows and guardrails

## Operating rule

Read `brand-context.md` before producing client or campaign work. Use TBC where a fact has not been approved. Never invent claims, audiences, capabilities, results, prices, or partner details.
